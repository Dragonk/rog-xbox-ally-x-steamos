# ASUS ROG Xbox Ally X (RC73XA) on SteamOS — fixes and enhancements

Small, self-contained modules that make hardware features of the **ASUS ROG Xbox Ally X**
behave on **SteamOS** the way they do on Windows. Each module lives in its own directory,
installs into the user's home, and ships a systemd guard so it survives SteamOS updates.

Real-device tested on RC73XA, SteamOS 3.9.5 (build 20261023.100), kernel 7.2.7-valve2,
Plasma 6.7.3, PipeWire 1.6.8, WirePlumber 0.5.18.

## Modules

| Directory | What it does | Status |
|---|---|---|
| [`dsp-lite/`](dsp-lite/README.md) | **Audio enhancement.** Runs the official ASUS/Dolby tuning for this codec on native PipeWire — no EasyEffects. Adds WebRTC microphone enhancement and one Plasma tray applet for both. | **recommended** |
| [`paddle-m1m2/`](paddle-m1m2/README.md) | Rear buttons (paddles M1/M2), plus a guard that keeps the InputPlumber sysext working after updates. | stable |
| [`fingerprint-ft9769/`](fingerprint-ft9769/README.md) | Power-button fingerprint reader (FocalTech FT9769): setup script, diagnostics and a guard. | stable |
| [`legacy-easyeffects/`](legacy-easyeffects/README.md) | **Legacy audio.** The old EasyEffects-based plugin. Kept for history, not recommended. | legacy |

Modules are independent: install only the ones you need. The one rule is to never run two
audio DSPs at once — see the note under "Audio" below.

## Requirements

- SteamOS 3.9 or newer on the RC73XA (other devices are untested here)
- Decky Loader for the audio tuning source (it generates the presets from the official ASUS package)
- `sudo` for the two units that must live outside the home directory

## Audio — `dsp-lite`

The chain is generated by the **Ally DSP** Decky plugin from the official ASUS
"Dolby Atmos driver" package (SHA-256 verified). `dsp-lite` then runs that generated chain
as a normal virtual sink on native PipeWire:

```
apps → allydsp_in → convolver → EQ (dialog) → multiband compressor (regulator) → limiter
     → allydsp_out → speakers
```

The default sink stays the **physical speaker**, so volume keys, the Steam OSD and mute act
after the DSP. Microphone enhancement is WebRTC noise suppression + AGC + high-pass.

### Install

1. Install the Ally DSP plugin (source of the tuning) and run its setup once, so
   `~/homebrew/data/Ally DSP/active/chain.conf` exists.
2. Copy the scripts and make them executable:

```bash
install -d ~/ally-dsp-fix/bin
install -m 755 dsp-lite/bin/*.sh dsp-lite/bin/lv2ls ~/ally-dsp-fix/
ln -sf ~/ally-dsp-fix/dsp.sh ~/.local/bin/dsp
```

3. Install the user units:

```bash
install -d ~/.config/systemd/user
install -m 644 dsp-lite/units/ally-dsp-{apply.service,apply.path,apply.timer,mic.service,streams.service} ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now ally-dsp-apply.path ally-dsp-apply.timer ally-dsp-mic.service ally-dsp-streams.service
```

4. Make the unit that Ally DSP writes run the generated chain instead of the smart filter
   (the drop-in is required on PipeWire 1.6.x — see `dsp-lite/README.md` for why):

```bash
install -d ~/.config/systemd/user/ally-dsp.service.d
cat > ~/.config/systemd/user/ally-dsp.service.d/50-render.conf <<'EOF2'
[Service]
ExecStart=
ExecStart=/usr/bin/pipewire -c /home/deck/ally-dsp-fix/render.conf
Environment="LV2_PATH=/home/deck/homebrew/plugins/Ally DSP/bin/lv2:/usr/lib/lv2"
EOF2
systemctl --user daemon-reload
```

Note the **quotes** around `LV2_PATH`: the plugin directory contains a space, and an
unquoted value is truncated by systemd, which silently disables the whole chain.

5. Expose `lv2ls` to the plugin's LV2 check (SteamOS ships liblilv but not the CLI) and
   install the tray applet:

```bash
sudo install -m 644 dsp-lite/units/lv2ls-bind.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now lv2ls-bind.service
install -d ~/.local/share/plasma/plasmoids
cp -r dsp-lite/plasma/org.deck.allydsp ~/.local/share/plasma/plasmoids/
systemctl --user restart plasma-plasmashell.service
```

Add the applet to the panel: right-click the system tray → *Configure System Tray* →
*Entries* → **Ally DSP** → *Always visible*.

### Daily use

```bash
dsp on | off | toggle | status
dsp preset movie balanced
dsp mic on | off
```

Left click the tray icon for the popup, right click for quick profiles. Everything is
bilingual: Polish or English follows the system locale.

### Do not stack DSPs

If the legacy EasyEffects variant is also installed, disable it before using `dsp-lite`
(`systemctl --user disable --now decky-rog-ally-audio-*`). Two DSPs in one path make every
listening test meaningless.

### What was measured

* linear stage matches the official FIR with **max 0.01 dB** deviation
* dynamic range across −60…0 dBFS: **18.7 dB** broadband, limiter holds −1.0 dBFS
* chain processes after a plain service restart: **+2.89 dB** (null target), **+9.34 dB**
  at −40 dBFS
* cost: **5.49 %** of one core, 46 MB RSS
* parity with Windows: regulator on, bass off, **leveler off** (not enabled in the ASUS
  tuning), default profile `movie`

## Rear buttons — `paddle-m1m2`

See [`paddle-m1m2/README.md`](paddle-m1m2/README.md). The guard re-applies the
InputPlumber sysext after SteamOS updates; install its unit and timer as described there.

## Fingerprint — `fingerprint-ft9769`

See [`fingerprint-ft9769/README.md`](fingerprint-ft9769/README.md). Run
`fingerprint-ft9769-setup.sh` once, then enable the guard unit/timer it installs.

## Legacy audio

`legacy-easyeffects/` holds the old EasyEffects-based plugin. It works, but it needs the
EasyEffects Flatpak running and duplicates volume handling. New setups should use
`dsp-lite`.
